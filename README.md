# psychotherapy-kotnik

Vue.js + Bulma static website about Psychotherapy Denis Kotnik in English language.


## Project Setup

Use Node.js 22.18 or newer in the 22.x series, or Node.js 24.11 or newer.
The `.node-version` file selects Node.js 22 for Cloudflare Pages.

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
# To preview the production build locally
npm run preview
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```
